# Py-converter

A simple graphical interface for **FFmpeg**, written in Python.

## Features

* 🎬 Video conversion
* ⚙️ FFmpeg-based processing
* 🖥️ Simple graphical interface
* 📦 Buildable as a standalone application

## Requirements

* Python 3
* FFmpeg

## Run

```bash
Download and start the realase
```

## Build

```bash
python3 video_converter.py
```
